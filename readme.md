# Blackchapel
Blackchapel is Go engine interfacing [Ebiten](https://ebitengine.org/)
meant to provide abstracted structure to create more complex RPG and 
visual novel games.

The engine is currently not yet suitable for creating games. You
can find roadmap for its development [here](todo.md).

### Features planned
- tile-based, 2D gamespace
- customisable game elements (e.g. GUI, activator's interfaces)
- basic game systems covered, such as inventory, dialogues, NPC 
                                schedules, pathing or save/load
- additional mechanics built through scripts (Python/Lua integration)

### Name
Blackchapel name has three sources:
- it's a little nod to [Whitechapel](https://www.youtube.com/watch?v=Ca1ZwkWUo-o) band
- it references **Black Cathedral**, an esoteric transition pass
  featured in Baedoor universe; it being reasoned as both physical
  reference (interiors in Blackchapel are surrounded by black colour,
  similarly to Void in Black Cathedral) and symbolic (this engine
  is my personal way to transition into more concrete 2D/3D game
  programming)
